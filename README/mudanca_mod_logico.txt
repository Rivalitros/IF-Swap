  CodHabilidade referencia Habilidade

                CodDesafio*, CodUsuario*, CodRespostaPai*)
  CodDesafio referencia Mural_Desafio
  CodUsuario referencia Usuario  (autor da resposta)
  CodRespostaPai referencia Resposta_Mural  (auto-relacionamento; nulo se for resposta raiz)

Mensagem (CodMensagem, Conteudo, Data_Envio, CodMatch*, CodUsuario*)
  CodMatch referencia Match
  CodUsuario referencia Usuario  (remetente)
