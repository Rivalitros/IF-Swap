# IF Swap

Projeto Integrador do Técnico em Informática Integrado ao Ensino Médio, IFSP Campus Barretos. Conecta estudantes, docentes e funcionários para trocas gratuitas de habilidades.

Use JavaScript, React/Vite, Node.js/Express, Socket.IO e PostgreSQL local. Preserve os fluxos, dados e identidade visual. Justifique mudanças no modelo relacional. Preserve os originais em `README/`, quando fornecidos. GitHub é reservado a código e documentação.

Leia este arquivo, `docs/ai/HANDOFF.md`, `IMPLEMENTATION_STATUS.md`, `NEXT_STEPS.md`, `DECISIONS.md` (na mesma pasta), `README.md`, a documentação técnica afetada e os originais pertinentes em `README/`. Confira o estado real do código e do Git antes de editar.

Em cada etapa consistente, execute as verificações disponíveis, atualize o handoff, status, próximos passos, changelog e contratos técnicos afetados. Revise os arquivos preparados, execute `git diff --cached --check` e faça um Conventional Commit. Envie a branch ao remoto configurado, se autorizado, e reporte hash e resultado verificado. Em interrupções, preserve checkpoints recuperáveis indicando trabalho pendente. Nunca force push, descarte trabalho alheio ou comite credenciais, dados pessoais, uploads, backups reais ou sessões locais. Revise os materiais acadêmicos antes de qualquer envio.
